# Security policy

Report suspected vulnerabilities privately to the repository owner using GitHub's private vulnerability reporting feature where enabled, or a trusted private contact method. Do not publish exploitable examples or sensitive data in public issues.

Study Sentinel is offline-first. Its command-line tool reads local CSV files and writes aggregate reports. Never upload personal or clinical data to public CI. The synthetic demo API is not an authenticated multi-user service. It must not be exposed to untrusted networks without an independent security assessment.
